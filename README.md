# GALex Digital

A digital, searchable companion to *A Greek and Arabic Lexicon (GALex)*, Volumes 1 (Alif) and 2 (Bāʾ), edited by Rüdiger Arnzen, Gerhard Endress and Dimitri Gutas (Brill, 2020 & 2021).

## What's here

- 942 Part-A entries across 272 Arabic roots, parsed into structured JSON
- 4,736 Part-B Greek-Arabic glossary lemmata
- Search across Arabic script, transliteration, Greek, and entry body
- Cross-references from glossary → lexicon entries
